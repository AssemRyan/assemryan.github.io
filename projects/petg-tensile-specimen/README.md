# PETG tensile specimen – design, print and simulation / Zugprobe aus PETG – Konstruktion, Druck und Simulation

**EN:** After Formnext 2026 I tested a PETG filament sample (Rosa3D PET-G True Matt) on my own FDM printer. ISO 527-2 type 1BA-style tensile specimens (parametric, 75 mm long, 5 mm neck, R30 transition), sliced in Cura (240 °C, bed 70 °C, 0.2 mm layers, 100 % infill) and printed on an Anycubic Viper. MATLAB (PDE Toolbox): quarter model, plane stress, mesh convergence (Kt ≈ 1.05), stiffness checked against an analytical strip integral (< 1 % difference). Virtual tensile test with assumed PETG values and the measured thickness (about 3.7 mm). Limits: the material values are assumptions, there is no real tensile test yet; the next step is a test in a laboratory with a tensile testing machine.

**DE:** Nach der Formnext 2026 habe ich ein PETG-Filamentmuster (Rosa3D PET-G True Matt) auf meinem FDM-Drucker getestet. Zugproben im Stil ISO 527-2 Typ 1BA (parametrisch, 75 mm lang, 5 mm Hals, R30-Übergang), in Cura gesliced (240 °C, Bett 70 °C, 0,2 mm Lagen, 100 % Füllung) und auf einem Anycubic Viper gedruckt. MATLAB (PDE Toolbox): Viertelmodell, ebener Spannungszustand, Netzkonvergenz (Kt ≈ 1,05), Steifigkeit gegen ein analytisches Streifenintegral geprüft (< 1 % Abweichung). Virtueller Zugversuch mit angenommenen PETG-Werten und der gemessenen Dicke (ca. 3,7 mm). Grenzen: Die Materialwerte sind Annahmen, ein realer Zugversuch fehlt noch; nächster Schritt ist ein Test im Labor mit einer Zugprüfmaschine.
